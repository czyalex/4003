# A股网格量化交易策略方案

> **创建日期**: 2026-03-18
> **风险提示**: 本文档仅为策略研究与规划，不构成任何投资建议。投资有风险，入市需谨慎。

---

## 一、策略概述

网格交易（Grid Trading）是一种基于价格区间震荡的量化策略，核心思想是：
- 在预设的价格区间内划分若干"网格"
- 价格每下跌一格 → 自动买入
- 价格每上涨一格 → 自动卖出
- 不预测方向，靠震荡赚取差价

**适用场景**: A股大部分时间处于震荡结构性行情，网格策略具有很强的普适性。

**不适用场景**: 单边趋势行情（单边暴涨时踏空、单边暴跌时深套）。

#### 为什么优先选ETF而非个股？

3. **分散风险** — 自带分散，不必担心单一公司黑天鹅
4. **适合自动化** — 流动性好，滑点小，适合程序化网格

## 三、核心参数设计

### 3.1 价格区间（上下限）

```
方法：基于估值分位数 + 近1-3年历史高低点

上限 = 近3年高点附近（高估线） + 1%缓冲
下限 = 近3年低点附近（低估线） - 1%缓冲
基准价 = 估值合理区偏下位置
```

**以沪深300ETF为例**:
- 假设近3年价格区间: 3.2元 ~ 4.8元
- 网格上限: 4.85元
- 网格下限: 3.15元
- 基准价(中轴): ~4.0元

### 3.2 网格间距

```
推荐公式: 间距 = 历史波动率(HV) × 1.0 ~ 1.5

- 宽基ETF (HV≈15-20%): 间距 1.5%-3%
- 行业ETF (HV≈25-35%): 间距 3%-5%
```

间距太小（<1%）→ 交易频繁，手续费侵蚀利润
间距太大（>10%）→ 难以触发交易，资金闲置

### 3.3 网格数量与资金分配

```
推荐：十等份法

总投入资金 / 网格数 = 每格交易金额

示例（10万元本金，沪深300ETF）:
- 网格数: 10格
- 每格金额: 1万元
- 底仓: 2-3万元（20%-30%）
- 备用金: 3万元（30%）保留应对极端下跌
- 网格资金: 4-5万元
```

### 3.4 进阶：金字塔加仓

```
越跌越多买，越涨越少卖:

下跌第1格: 买入 5% 资金
下跌第2格: 买入 7% 资金
下跌第3格: 买入 10% 资金
下跌第4格: 买入 13% 资金
下跌第5格: 买入 15% 资金

（上涨反向操作）
```

### 3.5 大小网格嵌套（可选）

```
大网格: 5% 间距 → 捕捉大波段
小网格: 1.5% 间距 → 中枢波动套利

适合有充足资金且希望提高资金利用率的投资者
```

## 四、风控规则

### 4.1 止损机制

| 条件               | 动作                     |
|--------------------|--------------------------|
| 价格跌破下限 5%    | 暂停网格，评估是否破位     |
| 价格跌破下限 10%   | 强制止损或转为长期持有     |
| 单标的浮亏 > 15%   | 减小网格仓位，补充备用金   |

### 4.2 止盈机制

| 条件               | 动作                     |
|--------------------|--------------------------|
| 价格突破上限        | 关闭网格，锁定利润        |
| 估值进入高估区      | 逐步收窄网格，减少买入    |
| 累计盈利达目标      | 提取部分利润，降低本金风险 |

### 4.3 仓位管理

```
总资金分配建议:
├── 宽基ETF网格: 50%-60%（沪深300 + 中证500）
├── 行业ETF网格: 20%-30%（1-2个行业主题）
└── 现金备用:    20%-30%（应对极端行情）
```

## 九、日内高频网格方案（T+0 多次触发）

> A股股票实行 T+1 制度（当天买不能当天卖），但以下品种支持 **T+0 日内回转交易**，可以实现一天内多次网格触发。

### 9.1 T+0 品种选择

#### 方案A：可转债（最佳日内网格标的）

| 优势                        | 劣势                        |
|-----------------------------|-----------------------------|
| 制度性 T+0，当天买卖不限次数 | 需开通权限（2年经验+日均10万） |
| 日内波动大（活跃标的3%-10%） | 有强赎风险                   |
| 无涨跌幅限制（有临停机制）    | 小盘转债流动性差              |
| 手续费低                     | 需注意到期转股/回售条款        |

**推荐标的筛选条件**:
```
- 日均成交额 > 5000万元（流动性保障）
- 转股溢价率 < 30%（股性强，波动跟随正股）
- 剩余期限 > 1年（避免临近到期波动异常）
- 价格区间: 100-150元（避免高价债的强赎风险）
- 日内振幅 > 1.5%（有足够波动触发网格）
```

**可转债日内网格参数**:
```
网格间距:    0.3%-0.8%（根据标的日内波动率调整）
网格层数:    10-20层
单笔金额:    总资金的 3%-5%
日内目标:    触发 5-15 次买卖
持仓策略:    日终清仓或保留底仓
```

#### 方案B：跨境/QDII ETF（制度性 T+0）

全市场约 **212只ETF** 支持 T+0，主要包括：

| 类别       | 代表标的                         | 日内波动 | 适合网格 |
|-----------|----------------------------------|---------|---------|
| 港股ETF   | 恒生ETF(159920)、H股ETF(510900)  | 1%-3%   | ★★★★   |
| 纳指ETF   | 纳指ETF(513100)、标普ETF(513500) | 1%-3%   | ★★★★   |
| 日经ETF   | 日经ETF(513880)                  | 1%-2%   | ★★★    |
| 黄金ETF   | 黄金ETF(518880)                  | 0.5%-2% | ★★★    |
| 债券ETF   | 国债ETF(511010)、城投ETF(511220) | 0.1%-0.5%| ★★     |

**跨境ETF日内网格参数**:
```
网格间距:    0.3%-0.5%（港股/美股ETF）
             0.1%-0.2%（债券ETF，配合0佣金）
网格层数:    15-30层
交易频率:    日内 8-20 次
注意事项:    关注折溢价率，溢价>2%时暂停买入
```

#### 方案C：底仓回转 T+0（普通ETF也能日内交易）

**原理**: 持有底仓 → 日内先卖后买（或先买后卖隔日卖底仓）

```
操作流程:
1. 建立底仓: 买入 N 份 ETF（如沪深300ETF 5万份）
2. 日内高点: 卖出底仓中的一部分（如1000份）
3. 日内低点: 买回同等数量（1000份）
4. 收盘时: 总持仓不变，但赚到了日内差价

本质: 用"已有仓位"实现变相 T+0
限制: 卖出数量 ≤ 底仓数量（不能裸卖）
```

**底仓回转网格参数**:
```
底仓规模:    总资金的 50%-70%
回转资金:    总资金的 30%-50%
网格间距:    0.3%-0.8%
日内目标:    3-8 次回转
适用标的:    任何高流动性ETF（包括T+1品种）
```

### 9.2 日内高频网格 vs 日间网格对比

| 维度         | 日间网格（T+1）      | 日内高频网格（T+0）    |
|-------------|----------------------|----------------------|
| 交易频率     | 周均 2-5 次          | 日均 5-20 次          |
| 网格间距     | 1.5%-5%             | 0.1%-0.8%            |
| 单笔利润     | 较大                 | 较小（积少成多）       |
| 手续费敏感度 | 低                   | 高（必须低佣）         |
| 适合品种     | 所有ETF/股票          | 可转债/跨境ETF/底仓回转 |
| 资金利用率   | 中等                 | 高                    |
| 技术要求     | 低（条件单即可）      | 高（需程序化或盯盘）    |
| 年化收益潜力 | 8%-15%              | 15%-30%+（高波动标的） |
| 风险         | 中等                 | 较高（高频磨损风险）    |

### 9.3 日内网格的关键风控

```
1. 最大日亏损限制:  单日亏损 > 总资金1% → 暂停当日交易
2. 单笔止损:       单笔浮亏 > 0.5% → 果断止损，不扛单
3. 尾盘纪律:       14:30后减少开新仓，避免隔夜风险
4. 手续费监控:      日手续费 > 当日盈利的30% → 检查间距是否过密
5. 折溢价监控:      跨境ETF溢价 > 2% → 暂停买入
6. 波动率自适应:    开盘30分钟计算日内波动率，动态调整间距
```

### 9.4 日内网格技术实现要点

```python
# 核心差异：日内网格需要分钟级/秒级行情数据

技术栈升级:
├── 行情源:  Level-2 行情（五档/十档盘口）或至少1分钟K线
├── 数据频率: 可转债→Tick级(3秒)  ETF→1分钟级
├── 下单延迟: < 500ms（券商API直连）
├── 券商选择: 支持量化API的券商（QMT/PTrade/miniQMT）
│             华泰(quanturtle) / 国金(QMT) / 国信(iQuant)
├── 运行环境: 本地运行（非云服务器，减少网络延迟）
└── 监控:     实时P&L面板 + 异常告警
```

### 9.5 推荐入门路径

```
入门最佳选择: 跨境ETF日内网格

理由:
1. 制度性T+0，操作简单无需底仓
2. 波动适中（1-3%），不像可转债那么剧烈
3. 流动性好，恒生ETF/纳指ETF日均成交10亿+
4. 可以用券商自带的条件单/网格单功能，无需编程

进阶路径:
跨境ETF条件单 → 可转债程序化网格 → 多品种日内高频网格
```

## 十、总结

A股ETF网格交易是一种**低门槛、适合震荡市**的量化策略：

1. **选对标的** — 优先宽基ETF（沪深300/中证500），波动率15%-25%
2. **设好参数** — 间距2%-3%，10格，留30%备用金
3. **做好风控** — 止损止盈明确，不贪不惧
4. **先回测再实盘** — 用5年数据验证，模拟盘跑2周
5. **小资金起步** — 先1-5万验证，逐步放大

**日内高频网格补充**:
6. **想日内多次触发** — 选可转债（T+0、高波动）或跨境ETF（制度性T+0）
7. **间距缩小到0.3%-0.8%** — 日内目标5-20次触发
8. **手续费是关键** — 必须低佣（万1以下），否则利润被侵蚀
9. **入门推荐** — 恒生ETF/纳指ETF条件单网格，无需编程
